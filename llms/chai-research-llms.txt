# Chai Research

> Chai Research Corp. (CHAI) is a Palo Alto consumer AI company building a character-and-story
> chat platform, where users create and talk to AI characters on iOS, Android and the web.
> Founded in 2021 by William Beauchamp, CHAI trains and serves its own conversational language
> models on an in-house GPU cluster, and runs Chaiverse — a developer platform where outside
> model builders submit HuggingFace-hosted language models, have them deployed to real Chai App
> users, and compete on a public leaderboard.

## Status of the developer surface

Chai Research has no public machine-readable API contract. A public Chat API
(`POST https://api.chai-research.com/v1/chat/completions`, `X-API_KEY` header) and a
`chaiverse` Python client were previously documented; both have been withdrawn without a
published deprecation notice. The documentation host `docs.chai-research.com` no longer
resolves in DNS, the API route returns a bodyless 404, and the `chaiverse` package and its
GitHub repository both return 404. The Chaiverse developer console is still live but
redirects every path to a login. See `lifecycle/chai-research-lifecycle.yml` for the probes.
